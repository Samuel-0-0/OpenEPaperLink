标签刷写器

模式



使用自动刷写，当您连接标签时，会立即将其刷写到最新固件。它会自动设置 MAC，尝试识别类型并开始刷写。目前仅支持 Solum M2 标签。



使用 OEPL-Flasher.py，您可以完全控制标签的刷写。
使用 --ip 参数连接到刷写器。

用法：
OEPL-Flasher.py [-h] [-t IP] [-f] [-i] [-eep] [-n] [-z]
[--pt] [--exit] [{read,write,autoflash,debug}] [filename]

{read,write,autoflash,debug} 要执行的命令
filename 读写命令的文件名

选项：
-h, --help 显示帮助信息并退出
-t IP, --ip IP 要使用的 IP 地址
-f, --flash 写入闪存
-i, --infopage 写入信息页/UICR
-eep, --eeprom EEPROM 操作
-n, --nrf82511 nRF82511 编程
-z, --zbs243 ZBS243 编程
--pt, --passthrough 刷写后进入串口透传以输出调试信息
--exit 发送数据后退出 EEPROM 加载器
